# WML Company Brain — Home

## Purpose

Single shared business-memory entry point for ChatGPT, Codex, and Obsidian.

## Core navigation

- [[02_PROJECTS/PROJECT_INDEX]] — active and historical business projects

- [[05_DECISIONS/DECISION_INDEX]] — durable decisions and defaults

## Default use

Before a business-sensitive implementation, Codex should read this Home note and then only the relevant linked notes. Do not load the entire vault indiscriminately.

## Source-of-truth rule

1. Explicit current user instruction
2. Current project/issue requirements
3. Company Brain durable rules and decisions
4. Existing implementation conventions

If a new user instruction is explicitly intended as a future default, persist it in the relevant Company Brain note.
