# WML Company Brain

This directory is the shared business knowledge layer used by ChatGPT, Codex, and Obsidian.

## Principle

GitHub is the canonical shared source. Obsidian is the human knowledge interface. Codex reads this directory before project execution. ChatGPT writes durable, structured memory here when the user explicitly asks to persist or synchronize it.

## What belongs here

- stable company context
- business projects and entities
- durable operating preferences
- document/output standards
- decisions and rationale
- structured conversation memory
- links to source documents and Feishu resources

## What does NOT belong here

- secrets, tokens, credentials
- raw access tokens or API keys
- temporary scratch work
- full raw chat dumps unless intentionally archived
- sensitive source documents that should remain only in Feishu/Drive
