# Document Default System

## Routing principle

Choose the document system based on audience and use case, not only file format.

### Government / school / domestic formal organizations
Use a formal Chinese-document/report system. Emphasize professional hierarchy, normative typography, stable spacing and restrained visual expression.

### Mature enterprise / large formal counterparty
Formal Word can reuse the government/school base system where appropriate, adjusted for corporate business communication.

### Visual business PDF
For enterprise proposals, commercial reports and rapid management reading, use a strong visual business-report system: executive summary, data cards, diagrams, timelines, matrices and clear decision blocks.

### Executive PPT
Default to a professional, vivid Canva-inspired executive presentation system. Use strong page-level conclusions, diagrams, cards, charts, timelines and decision logic.

### Small counterparty / investor / pitch
Allow stronger visual storytelling and pitch-style information density while preserving professionalism.

## Default behavior

If the user does not explicitly specify a template, infer the audience and route automatically. Explicit current-task instructions override these defaults.
